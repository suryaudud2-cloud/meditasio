# Meditasi Harian

Aplikasi web meditasi: frekuensi solfeggio, binaural beats, afirmasi (dengan suara), timer sesi, dan panduan napas 4-4-6. Bisa dipasang di HP (PWA) dan dibuka offline.

## Cara deploy di GitHub Pages
1. Upload semua file di folder ini ke repository (di root, bukan di dalam subfolder).
2. Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save.
3. Buka `https://USERNAME.github.io/NAMA-REPO/`.

## Pasang di Android
Buka alamat situs di Chrome → menu ⋮ → *Tambahkan ke layar utama* / *Instal aplikasi*.

## Catatan
Frekuensi ini untuk relaksasi, bukan pengganti perawatan medis. Gunakan headphone untuk mode binaural dan jaga volume tetap nyaman.
